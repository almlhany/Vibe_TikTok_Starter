# Vibe — مشروع فيديوهات قصيرة

هذه هي النسخة الأولى التي تعمل من Acode كواجهة ويب:
- تمرير فيديوهات عموديًا مثل تطبيقات الفيديو القصيرة.
- تشغيل/إيقاف الفيديو حسب ظهوره على الشاشة.
- إعجاب ومشاركة.
- إنشاء فيديو من ملفات الجهاز.
- صفحة ملف شخصي.
- حفظ الفيديوهات التجريبية محليًا.

## مهم
الرفع الحالي محلي للتجربة فقط. لكي يصبح التطبيق Online ويشاهده جميع المستخدمين نحتاج المرحلة الثانية:
1. قاعدة بيانات ومصادقة.
2. تخزين فيديوهات على الإنترنت.
3. API للمنشورات والتعليقات والإعجابات والمتابعة.
4. نظام إشعارات.
5. لوحة إدارة.
6. تحويله إلى APK/PWA.

لا تضع أي مفتاح سري للخادم داخل JavaScript الذي سيصل للمستخدمين.
